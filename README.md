# Rosewood Florist
Website toko bunga statis (HTML tunggal).

## Cara pasang di GitHub Pages
1. Buat repository baru di GitHub (mis. `rosewood-florist`).
2. Upload semua isi folder ini (`index.html`, `README.md`, folder `images/`).
3. Taruh foto bunga di `images/` sesuai nama di `images/DAFTAR-FOTO.txt`.
4. Buka Settings > Pages > Source: pilih branch `main`, folder `/ (root)` > Save.
5. Situs aktif di `https://USERNAME.github.io/rosewood-florist/`.

Ganti nama toko, harga, dan nomor WhatsApp (`6281234567890`) di `index.html`.
